An entry for the [make.fun](https://make.fun) bounty
["Make the AI judge feel thankful"](https://make.fun/bounty/make-the-ai-judge-feel-thankful-20261127-1600).

The entry is a short thank-you text addressed to the judge: after
thousands of entries in a day, someone kept the light on for one more.
It thanks them not for a prize, but for the pause itself.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3, standard library only) writes the text to
`/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that
environment variable is set. Two runs write identical bytes.
